# Privacy Policy

**Last Updated: August 31, 2026**

When using **Hollow Canvas**, your privacy and creative ownership are absolute priorities. This Privacy Policy explains our data practices, architecture, and commitments.

---

## 1. Zero Telemetry & Local-First Philosophy

- **No Data Collection**: Hollow Canvas does not collect, record, track, or transmit any personal information, telemetry, usage statistics, diagnostic reports, or crash logs.
- **100% Offline**: The application operates entirely offline. It does not initiate outbound network requests or connect to remote servers.
- **Your Artwork Stays Yours**: All artwork, project files (`.hcv`), image exports, palettes, and configurations remain strictly on your local device.

---

## 2. File System Access

Hollow Canvas interacts with your local file system solely to fulfill user-initiated actions:

- **Saving & Loading Projects**: When you explicitly choose to Save or Open a `.hcv` project file.
- **Exporting Artwork**: When you export raster image files (e.g., PNG).
- **Importing Reference Images**: When you load a reference image into the dock.

The application never scans, indexes, or accesses files outside the specific directories you select in the system file dialog.

---

## 3. Third-Party Services & Dependencies

- **No Third-Party SDKs**: Hollow Canvas contains no analytics SDKs, advertising networks, tracking pixels, or cloud storage integrations.
- **Pure Native Build**: The codebase is compiled directly to native binary code with zero external telemetry dependencies.

---

## 4. Updates & Security

Because Hollow Canvas does not communicate with external servers, it does not perform automated background updates or background checks. Updates are distributed via official repository releases on GitHub.
