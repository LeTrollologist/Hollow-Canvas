# Aurelia v2.4.0 — Lamplight

The studio stops looking like a framework demo and starts looking like a tool you paid for.

## Typography

The UI was set in egui's bundled Ubuntu. It now loads the system's own faces at
runtime (`aurelia-ui::fonts`): **Segoe UI** Regular / Semibold / Light and **Cascadia
Mono**, with egui's bundled families kept as fallbacks for emoji, symbols and non-Windows
builds — so the build still runs anywhere.

Hierarchy now comes from weight, not just size: headings and section captions use a
semibold *display* family, the wordmark a light *brand* family, metrics a mono family.

## Surfaces and gloss

New primitives in `aurelia-ui::design` give every surface the same grammar:

- `gloss()` — soft drop shadow, body fill, a 52 % top sheen and inner hairlines.
- `vgradient()` — shallow vertical gradients for panels, the header and the status bar.
- `fade_rule()` — rules that dissolve into the surface instead of stopping dead.
- `gloss_button()` — raised controls with **damped 120 ms** hover/press, so the chrome
  glides instead of flickering.
- Section captions: a 2 px gold tick, letterspaced champagne caps, and a fading rule.

Applied to: the header (lamp mark, light wordmark, gold version chip), the tool shelf
(accent bar on the active tool), presets, canvas operations, the swap button, palette
tiles (sheen, shadow, animated hover ring), colour slots (outer glow when active), layer
cards (tinted per layer kind), and floating scrollbars that no longer carve a gutter.

## Studio depth

The canvas no longer floats in a void: the viewport is a lamp-lit backdrop gradient
(lamplight above, deep ink below) with a wider, softer artboard shadow, so the artwork
reads as paper resting on a lit surface.

## Rulers, set in type

The numerals were a hand-rolled 5×7 bitmap table blitted at 2× — every stem a hard 2×2
block, no antialiasing, and no relation to the UI's typeface. They are now drawn by egui
on a foreground layer:

- same face as the chrome, antialiased;
- placement driven by **real glyph metrics** (`ruler_text::place_labels`), keeping numbers
  inside the canvas, inside the strip and at least 7 px apart;
- the vertical strip is rotated with `TextShape`, reading upwards like a professional
  ruler.

The bitmap font, its drawing helpers and the tests that only guarded that font are gone;
the layout pass has its own tests (no overlap, gap honoured, inside canvas, inside strip,
degenerate measurements rejected).

## Fixes

- `installer/aurelia.iss` defaulted `MyAppVersionNumeric` to `2.2.2.0`. The pipeline passes
  the value at build time, so shipped installers were always correct, but a manual ISCC
  run would have produced a mis-versioned installer. The default is now rewritten and
  validated with the rest of the declarations.
- The pipeline's declaration rules missed **intra-workspace dependency pins**
  (`aurelia-core = { path = "..", version = "x.y.z" }`), so bumping a release by hand made
  stage 2 fail on files that were otherwise correct. Those pins are now normalised too.
