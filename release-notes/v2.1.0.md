# Aurelia v2.1.0

An installer, a new release pipeline, and the end of VPack packaging.

## What's new

### Windows installer

Aurelia now ships a real Windows installer (`Aurelia-Setup-2.1.0.exe`) built with Inno Setup,
adapted from Inkwell's installer flow:

- **Per-user install** into `%LOCALAPPDATA%\Programs\Aurelia` — no administrator rights, no UAC prompt.
- **Optional file associations** for `.aur` (and legacy `.hcv`) using the same `Aurelia.Project`
  ProgID the app registers itself, so double-click opening and `--register-shell` agree.
- **Desktop shortcut** (opt-in), Start-menu entries, uninstall entry with the app icon.
- Uninstall removes an extension association **only if it still points at Aurelia**, so it never
  steals a file type you reassigned to another editor.
- Close-applications-on-upgrade, `lzma2/ultra64` compression, signed-size PE metadata.

The portable `Aurelia-v2.1.0-win64.zip` remains available for people who prefer a bare folder.

### Release pipeline (adopted from Morrow)

`scripts/pipeline.py` was rewritten around the Morrow release model — staged, resumable and
self-verifying — with Aurelia's packaging plugged in:

| Stage | What it does |
|---|---|
| `preflight` | Toolchain (cargo), Inno Setup discovery, git branch/remote checks |
| `version` | Rewrites every version declaration to the tag and *proves* they agree |
| `build` | `cargo build --release -p aurelia-app` |
| `test` | `cargo test --workspace`, pass/fail counts recorded |
| `package` | Portable zip + Inno Setup installer + release notes in `dist/<tag>/` |
| `verify` | `SHA256SUMS.txt`, zip integrity, installer PE sanity, ledger drift check |
| `publish` | Commits only pipeline-owned files, annotated tag, push, origin verification |
| `ship` | Uploads the verified bytes to the GitHub release page over REST |

Supporting pieces: `--from`/`--skip`/`--dry-run`/`--no-publish`/`--no-bump`/`--force`/`--clobber`,
per-tag records in `releases/<tag>.json`, authored notes in `release-notes/<tag>.md`,
`scripts/release_page.py` for uploads, and a Makefile that exposes every stage.

### VPack retired

`.vpack` archives, Ed25519 publisher signing and the VirusTotal upload step are gone for now.
Downloads are now:

| Asset | Purpose |
|---|---|
| `Aurelia-Setup-2.1.0.exe` | Per-user installer (recommended) |
| `Aurelia-v2.1.0-win64.zip` | Portable folder |
| `SHA256SUMS.txt` | SHA-256 for both, generated during `verify` |
| `RELEASE_NOTES.md` | This document, also used as the release body |

Signing may return later; the `keys/` folder is kept unused for that reason.

## Upgrading from 2.0.0

2.0.0 shipped VPack archives only. Install this version with the new Setup executable; your
`.aur` projects and the app's own settings under `%LOCALAPPDATA%\Aurelia` are untouched.
