# Aurelia v3.5.0 - measurement guides, Move modes and snapping

This release turns the viewport into a working cutting mat and adds the first persistent
editor state to AUR. It also includes a project-file allocation fix and release-tooling repairs.

## Added

- **Draggable guides and movable grid origin** from the rulers, with `+ H`, `+ V`, `Clear`,
  `Lock guides`, and persisted positions.
- **Move tool modes**: **Selected layer only** and **Full move**. Full move selects the topmost
  visible, unlocked layer by native alpha; guides remain independently draggable unless locked.
- **Snapping** to guides, canvas edges/centre and other layers' alpha-content bounds, for layer
  moves, guide moves, marquee edges and lasso points. Threshold is 6 screen pixels; `Alt`
  bypasses; a gold indicator shows the active target.
- **Straight-edge ruler**: movable, rotatable and stretchable, with tick labels, total length and
  angle readout. `Shift` snaps rotation to 15 degrees. **Draw along ruler** projects freehand
  strokes onto its centreline.
- **AUR editor state**: guides, grid origin and straight-edge ruler persist in an additive
  `AED1` section after the preview. Old files load with defaults; old readers ignore the
  trailing section. See `docs/PROJECT_FORMAT.md`.

## Fixed

- **Unbounded text-layer allocation.** A crafted project could claim up to 4 GiB of text content
  and trigger allocation before the truncation was detected. Text content is now bounded to
  8 MiB before allocation, and oversized saves are rejected.
- **Stale guide/ruler drag state** could consume later mouse moves after a lost mouse-up,
  collapsing freehand strokes to a dot. A new primary-button press now clears the drag.
- **Release versioning** now rewrites only workspace package versions in `Cargo.lock`, never
  dependency pins.
- **Packaging** now uses the executable produced by the build stage instead of an unset
  environment variable.
- **VirusTotal scanning** covers the ZIP and installer payloads, not detached signatures or the
  checksum manifest.
- **SECURITY.md** is part of the release version set.

## Integrity and unsigned distribution

- SHA-256 manifests and detached Ed25519 signatures cover the ZIP, installer and
  `SHA256SUMS.txt`.
- The installer is **not Authenticode-signed**, and this is a permanent distribution constraint.
  Windows SmartScreen may warn; verify the SHA-256 and Ed25519 signature before running.

## Compatibility

- AUR v1/v2 load read-only; saves continue to write v3. The `AED1` editor section is optional.
- 8-bit and 16-bit documents, transforms, filters and the existing test oracles are unchanged.
- The bilinear transparent-edge behaviour remains a pinned, accepted limitation: transparent
  black neighbours darken edges, transparent coloured neighbours tint them. Use Nearest for hard
  cutouts.
- The viewport remains an 8-bit presentation of 16-bit documents.

## Verified

- `cargo test --release --workspace`
- Sparse 16-bit benchmark: 0.70 against the 0.60 budget (`gate_2_throughput_and_memory`).
- Full release pipeline: preflight, version, quality, build, package, sign, scan, tag, publish,
  verify.
