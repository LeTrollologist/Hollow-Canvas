# Aurelia v2.1.1

A packaging-correctness release: the About dialog now describes what 2.1.0 actually
ships, and the pipeline learned to keep `INSTALL.md` in version lockstep.

## Fixes

- **About dialog** no longer advertises the retired VPack distribution or the old
  Ed25519 chain of trust. It now reads *"Portable Zip + per-user Inno Setup installer
  (SHA-256 verified)"*, and the Explorer-integration line lists `.aur` plus the formats
  the shell menu actually registers (`.tga`, `.tiff`, `.ico` included).
- **Pipeline**: `INSTALL.md` joined the version-declaration set, so install paths in the
  documentation can no longer drift behind the tag.

## Unchanged from 2.1.0

- Per-user installer: `Aurelia-Setup-2.1.1.exe` → `%LOCALAPPDATA%\Programs\Aurelia`,
  optional `.aur`/`.hcv` associations, uninstall that leaves reassigned file types alone.
- Portable `Aurelia-v2.1.1-win64.zip`.
- Staged release pipeline (Morrow model), SHA-256 manifest, per-tag release record.
- 50 workspace tests passing.
