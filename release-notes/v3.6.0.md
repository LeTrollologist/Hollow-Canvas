# Aurelia v3.6.0 — editing workflows

This release closes the workflow gaps that made the editor feel incomplete without touching the
rendering architecture. Every change in the milestone is covered by tests; the 8-bit compositor
oracle, the filter digests and the 16-bit paint/layer fixtures are unchanged.

## Added

### Paint directly on layer masks (#35)

Select a layer's ◐ mask badge and freehand strokes now write mask alpha instead of pixels.
White reveals, black conceals, the eraser always conceals, and the brush's size, hardness,
opacity, spacing and the live selection all apply. A ruby overlay shows what the mask hides and
is rebuilt only when the mask changes. Mask strokes are recorded through the history stack as
mask snapshots, and painting a mask on an RGBA16 document leaves the layer's storage format and
pixels untouched.

### Selection combine modes (#36)

Replace / Union / Subtract / Intersect are a sticky mode in the Select menu and the selection
HUD; <kbd>Shift</kbd>, <kbd>Alt</kbd> and <kbd>Shift</kbd>+<kbd>Alt</kbd> override the mode for
one gesture. Combination preserves fractional coverage, an empty result clears the selection, a
no-op records nothing, and committed selection edits are undone ahead of document history.

### Preferences interface (#37)

*File → Preferences* (<kbd>Ctrl</kbd>+<kbd>,</kbd>) exposes the settings that already existed in
the preferences file: autosave on/off and interval, the undo-memory budget, default JPEG export
quality, and the Dawn/Dusk/Ember theme. Values are validated (interval 15–3600 s, budget
16–4096 MiB, JPEG 1–100), reset to defaults with one button, applied immediately, and saved
with an error reported in the dialog if the write fails.

### History panel (#38)

The right dock lists retained undo steps oldest-first and redoable steps nearest-first, with the
current document state marked between them, each step's memory cost, and the total against the
configured budget. The core exposes a read-only entry API; inspecting history cannot change the
stacks or the dirty-tracking generation. Redo memory is now accounted for as well.

### Persistent ruler, guide and snap interaction (#41)

Guides, the straight-edge ruler and snapping moved out of the Move tool into an always-visible
*Guides & Snapping* section. Guide and ruler drags work with any tool, guide locking is a global
state, and ruler presets (0° / 30° / 45° / 60° / 90°) apply as actions instead of toggles.

### Ruler snapping and guide handles (#39)

The straight-edge ruler is a real snap target: points snap to its centerline at any angle,
layer moves slide along the ruler's normal, and exact ruler/guide intersection points win over
axis snaps. An active ruler snap draws a crosshair plus the ruler line. Painting snaps to the
ruler within the snap threshold, independent of tool. Guide handles keep their 5 px hit band at
every zoom level.

### Tool and brush reset (#42)

*Reset Tool* and *Reset Brush* in the tool properties restore the active tool's own parameters
or the shared brush shape/dynamics to their creation defaults. Colours, other tools' unique
parameters and document pixels are untouched; tools with nothing to reset say so.

## Compatibility

- AUR v1/v2 load read-only; saves continue to write v3.
- Preference files gain `undo_budget_mb`; older files load with defaults and every numeric field
  is clamped, so a missing or damaged key cannot stop startup.
- Layer masks remain 8-bit storage by design; mask painting in a 16-bit document does not
  convert the layer.
- The accepted bilinear transparent-edge limitation and the 8-bit viewport presentation are
  unchanged.
