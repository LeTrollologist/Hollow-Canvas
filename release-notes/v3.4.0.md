# Aurelia v3.4.0 — native 16-bit editing

This release completes the native 16-bit storage program. RGBA16 documents are now editable
end to end, including free transform, with the document's own storage width carried through
preview, commit, cancel and history.

## Highlights

- **Native 16-bit editing everywhere.** Paint, erase, fill, gradients, shapes, text, filters,
  selection fill/stroke, flip/rotate/crop/scale, compositing, merge-visible, merge-down and
  **free transform** run at the document's storage width. Nothing is staged through an 8-bit
  copy behind your back.
- **Free transform is native.** The session stores a typed `TransformPatch` instead of a
  `Vec<u8>`, previews restore from storage bytes, and cancel restores the five observational
  invariants: bytes, format, active layer, undo/redo stacks and dirty state.
- **16-bit performance is measured, not assumed.** The completion baseline records a sparse
  `Srgb16`/u8 ratio of 0.67 against the 0.60 budget, general-path 4-layer 1080p compositing at
  105.4 MPix/s opaque, and 16-bit brush throughput 5% above 8-bit on the test machine.

## Known limitation

Bilinear source interpolation still averages colour and alpha independently, as it did at
8 bits. A fully transparent transform border whose RGB is not black can therefore darken the
interpolated edge. Use **Nearest** for hard-edged cutouts or keep the RGB under zero-alpha
border pixels black. This is scheduled as a stabilization item and is not a 16-bit storage
gap; see `docs/16bit-plan.md`.

## Compatibility and upgrade notes

- AUR v3 files, including 16-bit layers, open and save unchanged. The release does not bump the
  project format.
- Existing 8-bit documents keep their byte-identical output; the pinned 8-bit transform digests
  are unchanged.
- The viewport still presents an 8-bit image because `egui` 0.28 textures are 8-bit. The document
  data stays 16-bit; export or reopen the file to inspect it.
- 32-bit floating-point / linear-light editing is **not** part of this release and has not been
  started.

## Verification

The workspace suite passes in debug and release, including the 8-bit digest gate and the new
16-bit transform acceptance tests. The exact counts and performance measurements are recorded in
`docs/16bit-plan.md` and `docs/PERFORMANCE.md`.
