# Aurelia v3.0.1

A viewport fix release. No file-format changes: v3.0.0 files open and save exactly as before.

## What changed

**Navigator thumbnail shows your artwork.** It used to draw an empty box with the viewport frame. It now shows a live downscaled copy of the canvas, built from the composite the renderer already makes each frame, so it follows your strokes without a second full-document composite.

**No more dead strip beside the panels.** The ruler size was counted twice when placing the viewport, which left a ruler-wide gap next to the left panel and under the header. The rulers now sit flush against the panels.

**The canvas is easier to see.** The default dark paper was almost the same color as the workspace behind it. The workspace is lighter and the canvas border is brighter.

**DPI handling fixed in the UI layer.** egui layout and pointer input were mixing physical pixels and points, which could push panels off-screen and misplace overlays at 125-200% display scaling. Everything is now converted at the egui boundary. This was tested at 100% scaling only, so reports from scaled displays are welcome.

**README corrected.** The viewport documentation now describes the software-rendered implementation instead of egui::CentralPanel.
