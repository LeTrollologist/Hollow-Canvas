# Aurelia v2.2.2

The About box and title bar stop lying about their version.

## Fix

The studio displayed a **hardcoded** version that had drifted three releases behind:
the title bar read `v1.0.3-alpha`, the About button's tooltip `(v1.0.2-alpha)`, and the About
dialog `Version 1.0.2-alpha` — while the build was actually 2.2.1.

All three now read `aurelia_ui::APP_VERSION`, which is `env!("CARGO_PKG_VERSION")`:

```rust
pub const APP_VERSION: &str = env!("CARGO_PKG_VERSION");
```

Because the release pipeline rewrites that `Cargo.toml` in lockstep with `aurelia-app`, the
version shown in the UI is now the version that was built, always.

## Guard against regression

- **Pipeline**: the `version` stage now scans every Rust source for quoted version literals
  and fails the release if one disagrees with the tag, with a message telling you to use
  `APP_VERSION`.
- **Test**: `app_version_is_semver_and_manifest_driven` asserts `APP_VERSION` equals the crate
  version and parses as `MAJOR.MINOR.PATCH`.

## Unchanged

Installer, portable zip, staged pipeline, SHA-256 manifest and the VirusTotal gate all behave
as in 2.2.1. The installer's four generic heuristic detections (no named family, unsigned
Inno package) are expected and disclosed in the release notes.
