# Aurelia v3.5.2 - guide, layer and panel fixes

This patch fixes the ruler/guide interaction problems reported after v3.5.1 and adds the missing
layer-order controls and panel width locks.

## Fixed

- **Guides can be pulled from the rulers with any tool.** Ruler guide creation was restricted to
  the Move tool; with Brush selected the drag fell through to the left-panel resize handle.
- **Dragging the left ruler no longer widens the tool panel.** Only a two-pixel strip at the
  panel edge remains a resize target.
- **Guides, ruler text, and the straight-edge ruler no longer draw over floating windows or
  dialogs.** They are painted below egui windows and clipped to the viewport.
- **Layers can be reordered with ↑ / ↓ controls**, with undo/redo support.
- **Layers have an explicit selection button**, so a previous layer can be selected without
  clicking into its name field.

## Added

- **Persisted sidebar width locks** at the top of both sidebars. A locked panel cannot be resized
  by dragging; the setting is saved in preferences and restored on restart.
- **Straight-edge ruler entry in the View menus** so it can be added without finding the Move
  tool properties.

## Compatibility

- AUR v1/v2 load read-only; saves continue to write v3.
- Guide/ruler/grid persistence is unchanged.
- The accepted bilinear transparent-edge limitation and 8-bit viewport presentation are
  unchanged.
