A UI fix release. No file-format changes: v3.0.1 files open and save exactly as before.

## What changed

**Tool badge no longer overlaps the stabilizer chip.** In the top bar, the "Brush · 4px" badge was drawn on top of the S-level (S-0..S-7) chip. It is now a regular button, so egui sizes it correctly at any brush size or S-level.

**README corrected.** The project format is now listed as AUR v3 instead of v1, and the duplicate `aurelia-io` entry in the repository structure is merged.

Credit goes to [@RustedLogic-oss](https://github.com/RustedLogic-oss) for providing the fix.
